# Chef Bono
## Your virtual chef

---

Chef Bono is an AI powered virtual chef. 
Bono stores 20.000 categorized human recipes (categorized as vegan, gluten free, high in protein, etc.)
Bono provides instructions, answer questions, communicates via speaker and microphone, watches kitchen table via camera for visual feedback to help preparing the perfect dish.

---

This is a final project for TED university.
